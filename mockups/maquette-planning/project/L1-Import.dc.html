Import Aurion

Le Planning reçoit les séances d’Aurion ; l’outil Intervenant les lit dans le Planning (Mon planning, puis contrats). Rien ne repart vers Aurion. Les séances se corrigent dans Aurion. Première livraison : les DPAE gardent leur propre requête vers Aurion ; elles liront le Planning plus tard.

Pas repris dans le lot 1 Catalogue et maquette pédagogique, arborescence des groupes, capacité et équipement des salles, calendriers de parcours et périodes de stage (absents d’Aurion), calendrier institutionnel, inscrits. Ils arrivent avec l’outil Planning complet. Outils qui lisent ces données Outil Intervenant : Mon planning (espace intervenant), puis interventions pour les contrats et avenants ; DPAE par journée après leur bascule (pour l’instant, requête DPAE propre vers Aurion). D’autres outils (Stage…) pourront les lire en consultation à leur déploiement. Identifiants Chaque séance reçoit un identifiant propre au Planning, qui ne change jamais ; l’identifiant et le code Aurion sont gardés comme anciens codes et restent cherchables.
